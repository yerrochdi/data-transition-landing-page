# NextMove — Vision produit V1

> Ton Career OS pour la vie data-augmentée.

## Positionnement

NextMove n'est **pas** :
- Un coach IA de transition (= remplaçable par ChatGPT)
- Une EdTech (= remplaçable par Coursera, OpenClassrooms)
- Un job board (= remplaçable par LinkedIn, Welcome to the Jungle)

NextMove **est** :
- La couche IA qui reste collée à la carrière du cadre **à vie**, à travers 3 phases distinctes :

| Phase | Quand | Objectif |
|-------|-------|----------|
| **Transition** | Mois 1-6 | Pivoter vers profil data-augmenté |
| **Installation** | Mois 6-12 | Réussir les 100 premiers jours du nouveau rôle |
| **Croissance** | Mois 12-∞ | Career radar, network compounding, salary intelligence |

## Cible V1

- **Âge** : 35-50 ans
- **Niveau** : Managers + Directors
- **Secteurs prioritaires** : Finance/Assurance + Tech/Conseil (les 2 verticales où le fondateur a le réseau et la crédibilité)
- **Géographie** : France + Europe

## Promesse au prospect

> *"Les cadres qui maîtrisent la data valent 2x plus. Découvre comment intégrer la data et l'IA à ton expertise — sans tout recommencer."*

Le user signe pour résoudre **3 problèmes que personne d'autre ne résout ensemble** :

### 1. "Je sais pas par où commencer"
→ Diagnostic IA → identification des gaps → parcours personnalisé sectoriel

### 2. "Je trouve pas les bonnes opportunités"
→ Job matching réel (France Travail API + scraping légal) avec scoring IA et explication du gap pour chaque offre

### 3. "Je sais pas activer mon réseau"
→ Network leverage LinkedIn (upload CSV) + IA matching contacts + génération messages personnalisés + tracker conversations

## Les 3 features WOW de la V1

### 🔴 Feature 1 — Job matching réel
- 50 vraies offres data/IA scrapées chaque semaine (France Travail API + scraping légal LinkedIn/Welcome to the Jungle)
- Score de compatibilité avec **explication IA** ("87% match, mais SQL manquant")
- Préparation entretien automatique sur la base de l'offre + CV utilisateur

### 🔴 Feature 2 — Network leverage LinkedIn
- Upload CSV des connexions LinkedIn (export utilisateur autorisé par LinkedIn)
- IA analyse → top 50 contacts pertinents pour la transition
- Génération de messages d'approche personnalisés
- Tracker des conversations entamées avec relances IA

### 🔴 Feature 3 — Livrables concrets (architecture parallèle au parcours)

**Principe** : les livrables sont **indépendants** du parcours. L'utilisateur peut piocher un brief dès J1, le terminer en 3-7 jours, et l'ajouter à son portfolio LinkedIn **immédiatement** (pas à la fin des 6 mois de parcours).

- Catalogue de 30-50 briefs (filtrables par compétence, secteur, durée)
- Templates fournis (Notion / Power BI / Notebook Python / 1-pager)
- Correction IA : score 0-100 + 3 points forts + 3 axes d'amélioration
- Portfolio dispo dès le 1er livrable validé (export PDF + lien public partageable)
- L'IA Copilot **suggère** le bon brief au bon moment du parcours, mais sans bloquer

**Pourquoi cette architecture parallèle** : un user qui doit attendre 6 mois pour avoir 1 livrable = user qui résilie au mois 2. Quick wins = engagement = rétention.

**Différenciation pricing** :
- Free : 1 brief découverte (ex: 1-pager cas d'usage IA)
- Boost : 5 briefs/mois
- Pro : illimité (incluant briefs premium avec correction IA approfondie)
- Sprint : 5 briefs sprint en 30 jours + revue 1:1 IA
